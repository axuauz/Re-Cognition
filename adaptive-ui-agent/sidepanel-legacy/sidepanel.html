EqualiUI는 사용자 특화 성향을 바탕으로 웹페이지 코드를 안전하게 제작합니다.

🧠 확인된 사용자 특화 성향 (User Persona)

에이전트가 대화와 명령을 분석하여 파악한 사용자님의 접근성 특성입니다. 웹페이지 방문 시 이 성향이 코드에 자동 반영됩니다.

📈 기능별 선호도 & RLHF 학습 가중치

에이전트가 사용 빈도와 사용자 피드백(👍/👎)을 반영하여 추천 가중치를 실시간으로 학습합니다.

🚫 RLHF 영구 배제 목록 (Negative Rules)

사용자가 "다시 추천하지 마" 또는 👎 거부한 기능입니다. 에이전트가 어떤 페이지에서도 절대로 추천하지 않으며 자동 반영에서도 완전히 배제(Zero Tolerance)합니다.

🌐 사이트별 자동 반영 코드 (Patch Registry)

에이전트가 도메인별로 제작하여 저장한 맞춤 주입 코드 목록입니다. 방문할 때마다 자동으로 수정 적용됩니다.

🔑 OpenAI API 설정

OpenAI API 키를 등록하면 최신 GPT-5.6-luna 기반의 심층 코드 제작 에이전트가 동작합니다. (미입력 시 내장 오프라인 신디사이저 동작)

확대·되읽기 같은 신호가 있을 때만, 사이트당 하루 1회, 페이지 제목과 측정값만 AI에 보냅니다. 제안은 승인 전에는 적용되지 않습니다.

🛡️ Human-in-the-Loop 안전 가드레일

  • 승인 전 무변경: 에이전트의 제안은 검토 카드에서 승인하기 전까지 페이지에 적용되거나 저장되지 않습니다.
  • 자동 안전 검사: 외부 전송·페이지 이동·양식 제출·쿠키 접근 코드는 차단되고, 기존 버튼의 기능/문구를 바꾸는 변경은 경고로 표시됩니다.
  • 민감 페이지 보호: 로그인·결제 페이지에서는 모양(CSS)만 바꿉니다.
  • 거절 학습: 거절한 제안과 이유를 기억해 같은 설계를 다시 제안하지 않습니다.
  • 1초 원상복구: Alt + Z로 즉시 복구되며 해당 사이트의 자동 적용도 함께 꺼집니다.
